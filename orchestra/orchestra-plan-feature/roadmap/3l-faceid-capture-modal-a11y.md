## User story

As a keyboard or screen-reader user, I want the biometric capture overlay to be a proper accessible dialog with focus trap and Esc-to-close, so I can operate and dismiss it.

## Scope

- **Goal:** Make the capture modal an accessible dialog (role, aria-modal, focus trap, Esc, labels, video aria-label).
- **Summary:** The modal is a fixed inset-0 z-50 biometric-capture overlay with no role='dialog', aria-modal, focus trap, Esc-to-close, or labelling, and the <video> has no aria-label. Add the dialog semantics, focus trap, Esc handler, labelling, and a video aria-label.
