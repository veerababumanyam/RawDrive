## User story

As a guest, I want the two public biometric endpoints in the same gallery to behave consistently, so face-match and photo-search return comparable results.

## Scope

- **Goal:** Make FaceMatch use the configurable threshold + clustered-only candidates that PhotoSearch already uses.
- **Summary:** FaceMatch uses a hardcoded threshold (0.6, clamped) and unclustered candidates; PhotoSearch/SearchByFace use configurable thresholds and clustered-only candidates. Route FaceMatch through the same configurable threshold source (face_thresholds) and the clustered-only candidate filter so both public endpoints share one behavioral contract.
- **Out of scope:** Consent/audit changes (that is 3b)
- **Out of scope:** Changing the embedding model or dimensions
