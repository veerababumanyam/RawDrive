<objective>
Fix broken avatar upload/display pipeline by migrating storage from PostgreSQL blobs to Cloudflare R2 for both personal AND company profiles, and create a shared AvatarDisplay component with initials fallback.

Purpose: Avatars are currently broken because they're stored as binary blobs in PostgreSQL. This plan migrates to R2 object storage (consistent with gallery images) and ensures graceful fallback when images fail to load. Per locked decision: "Company profile avatars follow same R2 pipeline as personal profiles."

Output: Working R2 avatar pipeline for both profile types (backend), shared AvatarDisplay component (frontend), database migration for R2 keys.
</objective>
