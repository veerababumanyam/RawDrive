  <behavior>
    - gallery_views table stores: id (UUID), gallery_id (UUID), workspace_id (UUID), visitor_token (VARCHAR 64), session_id (VARCHAR 64), device_type (VARCHAR 20), browser (VARCHAR 50), os (VARCHAR 50), country_code (CHAR 2), region (VARCHAR 100), referrer_domain (VARCHAR 255), time_spent_seconds (INT), viewed_at (TIMESTAMPTZ), created_at (TIMESTAMPTZ DEFAULT NOW)
    - Indexes on: (gallery_id, viewed_at), (workspace_id, gallery_id), (gallery_id, visitor_token)
    - GalleryAnalyticsRepository.insert_view(view_data) inserts a view record
    - GalleryAnalyticsRepository.get_summary(gallery_id, workspace_id, start_date, end_date) returns aggregated stats
    - GalleryAnalyticsRepository.get_daily_stats(gallery_id, workspace_id, start_date, end_date) returns per-day breakdown
    - GalleryAnalyticsRepository.get_device_breakdown(gallery_id, workspace_id) returns device type counts
    - GalleryAnalyticsRepository.get_geo_breakdown(gallery_id, workspace_id, limit=10) returns top countries
  </behavior>
  <action>
    1. Create Alembic migration `0205_add_gallery_views_table.py`:
       - Table: gallery_views with columns as specified in behavior
       - Indexes: idx_gallery_views_gallery_date ON (gallery_id, viewed_at DESC), idx_gallery_views_workspace ON (workspace_id, gallery_id), idx_gallery_views_visitor ON (gallery_id, visitor_token)
       - Chain after migration 0203 (gallery_downloads from Phase 19)

    2. Create `services/gallery-service/src/schemas/analytics.py` following ProfileView pattern:
       - GalleryViewCreate: visitor_token, session_id, device_type, browser, os, country_code, region, referrer_domain
       - GalleryAnalyticsSummary: total_views, unique_visitors, avg_time_spent_seconds, views_today, views_this_week, views_this_month
       - DeviceBreakdown: desktop_count, mobile_count, tablet_count, desktop_pct, mobile_pct, tablet_pct
       - GeoEntry: country_code, country_name, count
       - GalleryAnalyticsTimeSeries: date, views, unique_visitors
       - GalleryAnalyticsResponse: gallery_id, summary, daily_stats (list[TimeSeries]), device_breakdown, geo_breakdown (list[GeoEntry]), download_summary (total_downloads, total_bytes from gallery_downloads), period_start, period_end
       - TrackViewRequest: visitor_token, device_type, browser, os, country_code, referrer_domain, time_spent_seconds (optional, sent on unload)

    3. Create `services/gallery-service/src/repositories/analytics_repository.py`:
       - Uses raw asyncpg queries (consistent with gallery-service pattern)
       - insert_view: INSERT INTO gallery_views with workspace_id isolation
       - get_summary: COUNT(*), COUNT(DISTINCT visitor_token), AVG(time_spent_seconds) with date range filter
       - get_daily_stats: GROUP BY DATE(viewed_at) with date range
       - get_device_breakdown: GROUP BY device_type with counts and percentages
       - get_geo_breakdown: GROUP BY country_code ORDER BY count DESC LIMIT N
       - get_download_summary: SELECT COUNT(*), COALESCE(SUM(file_size), 0) FROM gallery_downloads WHERE gallery_id = $1 AND workspace_id = $2
       - ALL queries filter by workspace_id (multi-tenant mandatory)

    4. Write unit tests mocking the DB connection for repository methods.
