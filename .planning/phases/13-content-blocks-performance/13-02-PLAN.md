       - Add a custom `useInView` hook or use `useRef` + `IntersectionObserver`:

         ```
         const [ref, inView] = useState/useRef pattern
         useEffect(() => {
           const observer = new IntersectionObserver(([entry]) => {
             if (entry.isIntersecting) { setInView(true); observer.disconnect(); }
           }, { rootMargin: '200px' }); // preload 200px before visible
           if (ref.current) observer.observe(ref.current);
           return () => observer.disconnect();
         }, []);
         ```
       - Wrap each embed (EmbeddedTikTok, EmbeddedSpotify) in the observer div
       - Before inView: render a placeholder div with same height (h-[400px] for TikTok, h-[352px] for Spotify) showing a subtle loading state (platform icon + "Loading..." text, themed)
       - After inView: render the actual embed component
       - Replace `motion.div` with `m.div` for LazyMotion compatibility
