  <action>
1. Install npm packages:
   ```bash
   cd frontend && pnpm add @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities react-best-gradient-color-picker
   ```

2. Create `frontend/src/contexts/ProfileEditorContext.tsx`:
   - Define action types: `SET_FIELD`, `SET_THEME`, `SET_DEVICE_MODE`, `SET_SECTION_ORDER`, `RESET`, `MARK_SAVED`, `SET_SAVING`
   - State shape extends EditorState from types/profileEditor.ts, adding:
     - `profileType: ProfileType` ('personal' | 'company')
     - `sectionOrder: string[]` (array of section IDs like ['header','bio','contact','socials'])
   - useReducer handles all actions, sets `isDirty: true` on any data change
   - Export `ProfileEditorProvider` that wraps children with context
   - Export `useProfileEditor()` hook returning state
   - Export `useProfileEditorDispatch()` hook returning dispatch
   - Provider accepts `initialProfile: Record<string, unknown>`, `profileType: ProfileType`, `initialThemeId?: string`, `initialSectionOrder?: string[]`
   - On mount, dispatch RESET with initial data

3. Create `frontend/src/hooks/useProfileAutoSave.ts`:
   - Accepts: `profileType: ProfileType`, `profileData: Record<string, unknown>`, `isDirty: boolean`, `onSaved: () => void`
   - Uses useRef for 2000ms debounce timer (clearTimeout on each change, setTimeout on dirty)
   - When timer fires, calls the appropriate service (personalProfileService.updateProfile or companyProfileService.updateProfile) via TanStack Query useMutation
   - On success: calls `onSaved()` which dispatches MARK_SAVED
   - On error: shows toast via useToastActions
   - Returns `{ isSaving: boolean, lastSavedAt: string | null, saveNow: () => void }`
   - `saveNow` is for manual save / beforeunload

4. Create `frontend/src/hooks/useProfileAutoSave.test.ts`:
   - Test: does not fire save when isDirty is false
   - Test: fires save after 2000ms when isDirty becomes true
   - Test: resets timer when data changes while dirty
   - Test: calls onSaved callback after successful save
   - Use vi.useFakeTimers, vi.advanceTimersByTime
  </action>
