<objective>
Optimize face processing performance: add pgvector HNSW index, batch centroid recalculation, eager model loading, and proper worker timeout enforcement.

Purpose: Without an index, similarity search is O(n) and will timeout at >100k faces. Centroid recalculation on every face assignment is wasteful. Lazy model loading causes cold start latency. Worker timeouts are defined but not enforced with asyncio.wait_for().

Output: HNSW index migration, batched centroid service, eager ONNX loading, enforced worker timeouts, performance regression tests.
</objective>
