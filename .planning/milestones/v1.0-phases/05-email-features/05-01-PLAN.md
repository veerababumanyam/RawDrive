RED phase: Create backend/tests/test_password_reset.py with 8 tests mocking database and EmailService. Tests must fail initially.

GREEN phase:
1. Create backend/src/app/services/password_reset_service.py following EmailVerificationService pattern:
   - TOKEN_TTL_HOURS = 1 (shorter than verification -- 1 hour expiry)
   - TOKEN_LENGTH = 64 (same as verification)
   - class PasswordResetService with methods:
     - async def request_password_reset(self, email: str) -> str | None
       - Look up user by email (case-insensitive). If not found, return None (no error).
       - Generate raw_token via secrets.token_urlsafe(TOKEN_LENGTH)
       - Hash with SHA-256, store in email_verifications table with verification_type='password_reset'
       - Invalidate any existing pending reset tokens for this user
       - Build reset_url = f"{settings.public_url}/reset-password?token={raw_token}"
       - Call email_service.send_password_reset_email(to_email, reset_url, user_name)
       - Return raw_token (for testing; endpoint ignores it)
     - async def validate_reset_token(self, token: str) -> uuid.UUID
       - Hash submitted token, look up in email_verifications where verification_type='password_reset' and status='pending'
       - Check expiry. Raise TokenExpiredError if expired.
       - Return user_id
     - async def reset_password(self, token: str, new_password: str) -> uuid.UUID
       - Validate token (reuse validate_reset_token)
       - Hash new_password using the same bcrypt method used in auth_service.py (find it by reading auth_service.py)
       - Update users table SET password_hash = new_hash WHERE user_id = user_id
       - Mark token as used (status='verified') in email_verifications
       - Return user_id
   - Use Redis cooldown key to prevent spamming reset requests (same pattern as EmailVerificationService)

2. Wire auth.py endpoints:
   - Update forgot_password (line 403-408): Call PasswordResetService.request_password_reset(email). Always return same MessageResponse regardless of result.
   - Add new POST /reset-password endpoint: Accept {token: str, new_password: str}. Call PasswordResetService.reset_password(token, new_password). Return 200 on success, 400 on invalid/expired token.

IMPORTANT: The forgot-password endpoint MUST always return the same response ("If the email exists, a reset link has been sent") to prevent email enumeration. Never return different HTTP codes for found vs not-found.
