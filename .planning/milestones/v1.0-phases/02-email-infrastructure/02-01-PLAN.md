**Part B: Create DNS setup guide**

Create `docs/email-dns-setup.md` documenting the DNS records needed for Postal email deliverability. Include:

1. **SPF record**: `v=spf1 ip4:<SERVER_IP> include:spf.postal.yourdomain.com ~all` on the sending domain
2. **DKIM record**: `postal._domainkey.yourdomain.com` TXT record (value generated by Postal after deployment via `postal default-dkim-record`)
3. **DMARC record**: `_dmarc.yourdomain.com` TXT `v=DMARC1; p=quarantine; rua=mailto:dmarc@yourdomain.com; pct=100`
4. **MX record**: For Postal's return path domain
5. **Reverse DNS (PTR)**: Needed for server IP to pass deliverability checks
6. **Steps to configure**: (a) Deploy Postal, (b) Run `docker exec rawdrive-postal postal default-dkim-record` to get DKIM value, (c) Add DNS records, (d) Wait 24-48h for propagation, (e) Verify with `docker exec rawdrive-postal postal check-dns`
7. **Note**: Port 25 outbound must be allowed by cloud provider. Many providers (AWS, GCP, Azure) block it by default -- document how to request unblock for each.
