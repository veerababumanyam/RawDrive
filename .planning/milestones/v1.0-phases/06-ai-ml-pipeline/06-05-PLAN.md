    - Test 4: get_cached_groups returns None when cache miss
    - Test 5: invalidate_cache deletes the Redis key

  <action>
    1. Create `services/similarity_cache_service.py`:
       - `SimilarityCacheService` class
       - `SIMILARITY_GROUP_TTL = 3600` (1 hour)
       - `CACHE_KEY_PREFIX = "similarity_groups:"`
       - `async cache_similarity_groups(session_id: UUID, groups: list[dict]) -> None`:
         a. Convert UUIDs to strings for JSON serialization
         b. `redis.setex(f"{CACHE_KEY_PREFIX}{session_id}", SIMILARITY_GROUP_TTL, json.dumps(groups))`
       - `async get_cached_groups(session_id: UUID) -> list[dict] | None`:
         a. `cached = redis.get(f"{CACHE_KEY_PREFIX}{session_id}")`
         b. Return `json.loads(cached)` if hit, None if miss
         c. Wrap in try/except for Redis errors -> return None
       - `async invalidate_cache(session_id: UUID) -> None`:
         a. `redis.delete(f"{CACHE_KEY_PREFIX}{session_id}")`
       - `get_similarity_cache_service()` singleton factory

  </verify>
