## 1. Schema Design

### Naming Conventions

*   **Tables:** `snake_case` (plural), e.g., `users`, `gallery_assets`.
*   **Columns:** `snake_case`, e.g., `created_at`, `workspace_id`.
*   **Foreign Keys:** `target_table_id`, e.g., `owner_id`.
*   **Indexes:** `ix_<table>_<columns>`, auto-generated by Alembic.

### UUID Primary Keys

Use UUIDv4 (or UUIDv7 if available) for all primary keys to allow easy distributed generation and security (non-sequential).

```python
from sqlalchemy.dialects.postgresql import UUID
import uuid

id = Column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
```

### Multi-Tenancy

**CRITICAL RULE:** Every table that stores customer data MUST have a `workspace_id`.

```python
workspace_id = Column(UUID(as_uuid=True), ForeignKey("workspaces.id"), nullable=False, index=True)
```

*   **Never** make `workspace_id` nullable for tenant data.
*   **Always** index `workspace_id` for filtering.

### Timestamps

Use UTC structure for all timestamps.

```python
from sqlalchemy import DateTime
from sqlalchemy.sql import func

created_at = Column(DateTime(timezone=True), server_default=func.now(), nullable=False)
updated_at = Column(DateTime(timezone=True), onupdate=func.now())
```

### JSONB for Flexibility

Use `JSONB` (binary JSON) for flexible metadata, not `JSON` (text). `JSONB` supports indexing and faster querying.

```python
from sqlalchemy.dialects.postgresql import JSONB

metadata = Column(JSONB, default={})
```

## 2. PostgreSQL Specifics

### Enums

Use PostgreSQL native `ENUM` types for fixed states within SQLAlchemy.

```python
import enum
from sqlalchemy import Enum

class UserRole(str, enum.Enum):
    ADMIN = "admin"
    EDITOR = "editor"
    VIEWER = "viewer"

role = Column(Enum(UserRole, name="user_role_enum", create_type=True), nullable=False)
```

**Note:** Changing ENUM values in Postgres requires migration steps (using `op.execute("ALTER TYPE ...")`).

### Arrays

Postgres supports native arrays. Use them for simple lists (e.g., tags) instead of a join table if relational integrity isn't strict.

```python
from sqlalchemy.dialects.postgresql import ARRAY, String

tags = Column(ARRAY(String), default=[])
```

## 3. Vector Search (pgvector)

We use `pgvector` for AI features (FaceIDs, Semantic Search).

### Column Definition

```python
from pgvector.sqlalchemy import Vector

# 768 dimensions for Google Gemini embeddings
embedding = Column(Vector(768))
```

### HNSW Indexing

Always create an HNSW index for performance on vector columns.

```python
from sqlalchemy import Index

__table_args__ = (
    Index(
        "ix_assets_embedding",
        "embedding",
        postgresql_using="hnsw",
        postgresql_with={"m": 16, "ef_construction": 64},
        postgresql_ops={"embedding": "vector_cosine_ops"}
    ),
)
```

### Similarity Search Query

Use the `<->` (L2 distance) or `<=>` (Cosine distance) operator.

```python
from sqlalchemy import select

stmt = select(Asset).order_by(Asset.embedding.cosine_distance(query_vector)).limit(5)
```

## 4. SQLAlchemy Patterns (Async)

We use **SQLAlchemy 2.0+** with `asyncio`.

### Engine Setup

```python
from sqlalchemy.ext.asyncio import create_async_engine, AsyncSession, async_sessionmaker

engine = create_async_engine(settings.DATABASE_URL, echo=False)
AsyncSessionLocal = async_sessionmaker(engine, expire_on_commit=False)
```

### Declarative Model

```python
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

class Base(DeclarativeBase):
    pass

class User(Base):
    __tablename__ = "users"
    id: Mapped[uuid.UUID] = mapped_column(primary_key=True, default=uuid.uuid4)
```

### Async Dependency

```python
async def get_db():
    async with AsyncSessionLocal() as session:
        yield session
```

### Queries (2.0 Style)

**Select:**

```python
result = await session.execute(select(User).where(User.email == email))
user = result.scalars().first()
```

**Update:**

```python
stmt = update(User).where(User.id == uid).values(name="New Name")
await session.execute(stmt)
await session.commit()
```

**Delete:**

```python
stmt = delete(User).where(User.id == uid)
await session.execute(stmt)
await session.commit()
```

### Handling Relationships (Lazy Loading)

Async SQLAlchemy cannot implicit lazy load. Use eager loading strategies:

```python
from sqlalchemy.orm import selectinload

stmt = select(User).options(selectinload(User.galleries))
```

`selectinload` is generally preferred for `one-to-many`. `joinedload` for `many-to-one`.

## 5. Indexing Strategy

*   **Foreign Keys:** Index all FKs to avoid full table scans on joins/deletes.
*   **Search Fields:** Add B-Tree indexes on frequently searched columns (`email`, `slug`).
*   **Filtering:** Composite indexes for common filter pairs (e.g., `(workspace_id, created_at)`).
*   **Partial Indexes:** Use `postgresql_where` for unique constraints on subsets (e.g., active users only).

```python
Index("ix_active_email", "email", unique=True, postgresql_where=deleted_at.is_(None))
```

## 6. Migrations (Alembic)

*   **Autogenerate is a draft:** Always review the generated migration file.
*   **Enum Changes:** Alembic doesn't detect Enum value changes well. Handle manually.
*   **Data Migrations:** Separate schema changes from data backfills if the backfill is heavy.
*   **Never commit local DB URL:** Keep `alembic.ini` generic or use env vars.

**Common Command:**

```bash
alembic revision --autogenerate -m "add_face_embeddings"
alembic upgrade head
```

## 7. Performance Tuning

*   **Connection Pooling:** Use `PgBouncer` in production (configured in `docker-compose.yml`).
*   **Batch Operations:** Use `session.execute(insert(Model), data_list)` for bulk inserts.
*   **Select Specific Columns:** Don't `select(Model)` if you only need IDs.
    ```python
    await session.execute(select(User.id, User.email))
    ```

## 8. Testing & Seed Data

*   **Fixtures:** Use `pytest` fixtures for database sessions.
*   **Isolation:** Tests should run in transaction rollback mode or use a separate DB.
*   **Test Users:** See `docs/TEST_USERS.md` for standard seed accounts.

```python
# conftest.py pattern
@pytest_asyncio.fixture
async def db_session():
    async with AsyncSessionLocal() as session:
        yield session
        await session.rollback()
```
