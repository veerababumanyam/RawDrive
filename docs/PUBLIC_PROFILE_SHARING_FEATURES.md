# RawDrive Public Profile Sharing Features

## Overview
RawDrive's Public Profile Sharing system provides photographers and studios with a professional online presence that seamlessly integrates with client management, galleries, and secure sharing capabilities.

## Core Features

### Public Profile Features
- **Custom Branding**: Upload logo, choose brand colors, create cohesive visual identity
- **Professional Information**: Display company details, specialties, years in business, certifications, awards
- **Contact Integration**: Primary and secondary emails/phones with visibility controls
- **Location & Service Areas**: Show geographic reach and service locations
- **Social Media Integration**: Link Instagram, Facebook, Twitter, and LinkedIn profiles
- **Custom Links**: Add portfolio websites, booking systems, or other important links
- **SEO Optimization**: Structured data and meta tags for better discoverability
- **Custom Domains**: Use your own domain (e.g., `studio.yourbrand.com`)
- **Mobile-First Design**: Responsive layouts for all devices
- **Lead Capture Forms**: Built-in inquiry forms that feed into CRM
