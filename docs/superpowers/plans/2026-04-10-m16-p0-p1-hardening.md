## Task 2: F-002 — Secure OAuth/login token flow (P0)

**⚠ SCOPE DISCOVERY (2026-04-10 session): Far bigger than audit summary.**
The actual current state (confirmed via file reads):
- `backend/internal/auth/handler.go:408-416` — OAuth callback embeds tokens in 302 redirect URL via `buildFrontendLoginRedirect` with `map{"access_token", "refresh_token"}`.
- `frontend/src/lib/auth.ts` — 119-line module. `persistAuthTokens(access, refresh, remember)` writes BOTH tokens to `localStorage` (or `sessionStorage`). Exposes `getStoredAccessToken()`, `getStoredRefreshToken()`, `getStoredAccessTokenClaims()`, `getStoredWorkspaceId()`, `getStoredPlatformRole()`, `getPostLoginPath()` — consumed across the entire frontend.
- `frontend/src/components/auth/LoginForm.tsx` — calls `persistAuthTokens` from BOTH the `?access_token=&refresh_token=` URL path (line 58) AND the `/auth/login` JSON response path (line 103).
- Estimated blast radius: every frontend API client site that currently sends `Authorization: Bearer ${getStoredAccessToken()}` must switch to `credentials: 'include'` OR get token from a React context populated from a refresh call.

**Full fix requires:**
1. Backend cookie setters in OAuth callback + `/auth/login` response (httpOnly, Secure, SameSite=Lax).
2. `/auth/logout` endpoint that clears the cookie.
3. Backend middleware that reads JWT from cookie AND from Bearer header (transition period) or cookie-only (clean cutover).
4. `/auth/session` endpoint that returns current user claims (so frontend doesn't need to decode JWT in JS).
5. Frontend: remove `persistAuthTokens`, `getStoredAccessToken`, etc. Replace with React context + `useSession()` hook backed by `/auth/session`.
6. Frontend: every existing `fetch` with `Authorization` header → `fetch` with `credentials: 'include'`.
7. OAuth callback: redirect to a server-rendered intermediate page that sets the cookie and then client-redirects to `/dashboard` WITHOUT tokens in URL.

**This is a ~15-25 file refactor minimum. It needs its own dedicated session.**

**Files (summary):**
- Modify: `backend/internal/auth/handler.go` (408-416, OAuth callback — set cookie, no query params)
- Modify: `backend/internal/auth/handler.go` (Login handler — set cookie, remove JSON tokens)
- New: `backend/internal/auth/session.go` + handler for `/auth/session` and `/auth/logout`
- Modify: `backend/internal/middleware/auth.go` (or wherever Bearer is read) — add cookie path
- Rewrite: `frontend/src/lib/auth.ts` → session context + hook
- Modify: `frontend/src/components/auth/LoginForm.tsx` — no persistAuthTokens
- Modify: ALL files in `frontend/src/lib/api/` that set Authorization header
- Tests: handler cookie round-trip, logout clears cookie, middleware accepts cookie auth

**Approach:** OAuth callback currently redirects with tokens in query string; frontend persists to localStorage. Must: (1) OAuth callback sets httpOnly cookies server-side and redirects to `/dashboard` with NO tokens in URL, (2) frontend reads from cookie (no localStorage), (3) refresh token lives only in httpOnly+Secure+SameSite=Lax cookie.
