  <project_name>RawDrive Digital Invitations &amp; Save-the-Date</project_name>

  <overview>
    RawDrive&apos;s Digital Invitations system is a comprehensive event invitation platform designed for Indian photographers, event organizers, and hosts to create, customize, share, and manage beautiful digital invitations with integrated RSVP management, guest tracking, analytics, and multi-language support. The system enables photographers to leverage workspace-scoped assets and the centralized design system to create professional invitations in under 5 minutes, eliminating printing and postage costs while providing real-time guest engagement tracking. The platform supports complex multi-day event structures (typical of Indian weddings with Mehndi, Sangeet, Ceremony, Reception), integrated QR codes, calendar synchronization, and email distribution with comprehensive security, audit logging, and GDPR/DPDP compliance. The feature is segmented across multiple specifications covering save-the-date basics (016), digital wedding invitations (017), production readiness (018), multi-language support (019), and RSVP security hardening (020).
  </overview>

  <development_guidelines>
    <guideline>Architecture: Microservices pattern with separation between invitation CRUD (main backend) and supplementary operations (dedicated microservice)</guideline>
    <guideline>API Design: RESTful endpoints with workspace routing, consistent response formats, semantic HTTP status codes, JWT authentication</guideline>
    <guideline>Code Organization: Services layer abstraction, dependency injection via FastAPI, configuration management via environment variables</guideline>
    <guideline>Database: Async operations with asyncpg, proper connection pooling, migrations via Alembic with down_revision tracking</guideline>
    <guideline>Caching: Redis with 10-minute TTL for analytics, cache invalidation strategies, cache-aside pattern</guideline>
    <guideline>Background Jobs: Celery for email operations with exponential backoff, rate limiting per workspace, delivery tracking</guideline>
    <guideline>Testing: Pytest for unit/integration tests with fixtures, asyncio support, security-focused tests (error leakage, XSS, guest isolation)</guideline>
    <guideline>Logging: Structured JSON logging with correlation IDs, PII filtering, log levels (DEBUG/INFO/WARNING/ERROR)</guideline>
    <guideline>Security: HMAC-SHA256 for tokens, Argon2id for passwords, HTML escaping, CSRF tokens, constant-time comparisons</guideline>
    <guideline>Monitoring: Prometheus metrics on critical paths, health checks for Kubernetes, Grafana dashboards for anomaly detection</guideline>
    <guideline>Type Safety: TypeScript for frontend, Pydantic models for backend, shared type definitions via @rawdrive/shared-types</guideline>
    <guideline>Error Handling: Custom exception classes, detailed error context, user-friendly error messages, error boundaries in React</guideline>
    <guideline>Frontend: React components for invitation creation, RSVP submission, check-ins, analytics, error boundaries with retry logic</guideline>
    <guideline>Documentation: OpenAPI/Swagger docs, migration descriptions, test coverage targets (95% for security-critical code)</guideline>
    <guideline>Deprecation: Backward compatibility where possible, deprecated exports marked with @deprecated comments, migration guides</guideline>
  </development_guidelines>
